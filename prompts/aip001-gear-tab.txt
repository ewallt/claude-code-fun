aip001 — Gear with Tabs App Builder

Using the input already in our conversation, build a single-file HTML web app. Output only the complete HTML — no explanation, no preamble, no markdown fences.

---

APP STRUCTURE

Single file. No external CSS frameworks. No CDN dependencies. Vanilla JS only.

Structure:
  <head>: meta charset, viewport, <style>
  <body>: <header>, tab bar, <main>, <footer>, <script>

---

HEADER

Three-column grid: empty left, centered title block, swatches right-aligned.

  <header>
    <div></div>
    <div style="text-align:center">
      <div class="site-title">[App Title]</div>
      <div class="site-subtitle">[Subtitle]</div>
    </div>
    <div class="theme-swatches" id="swatches" style="justify-content:flex-end"></div>
  </header>

Header: position sticky, top 0, z-index 10.

---

Default theme on load: navy.

---

TABS

Derive tab names from the data — never hardcode in HTML. Render dynamically.

Active tab: color var(--brand), border-bottom 3px solid var(--brand).
Inactive tabs: color var(--text-muted).

---

CARDS

Adapt card structure to the content. Use:
  Background: var(--card-bg)
  Border: var(--border)
  Body text: var(--text-card)
  Secondary text: var(--text-muted)
  Accents / titles: var(--brand) — page-level only; on Explorer dark cards use var(--text-card) instead

Every color references a CSS variable. No hardcoded hex anywhere except inside THEMES and :root.

---

RULES

- All hover, active, focus states use CSS variables
- Add smooth transitions to body and key structural elements:
    transition: background-color 0.3s, color 0.3s, border-color 0.3s
- Explorer note: --brand (#7a3e10) is calibrated for the light parchment background. Card text uses --text-card, not --brand.

---

FOOTER

Centered, var(--text-muted), border-top 1px solid var(--border). Brief attribution line.

---

INPUT INTERPRETATION

From the input already in context, identify:
  1. App title and subtitle
  2. Tab categories — what naturally groups the content
  3. Card structure — what fields each item needs

If the input is a document: derive categories from its sections.
If the input is a list: derive categories from item types or tags.

Use judgment — tabs should reflect the natural shape of the data, not be invented.

---

OUTPUT

Complete single-file HTML only. Nothing before or after it.

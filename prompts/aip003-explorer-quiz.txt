AIP003 — Explorer + Quiz App Builder

Ask the user for the topic before proceeding. Once you have it, build a single-file HTML web app and output only the complete HTML — no explanation, no preamble, no markdown fences.

---

APP STRUCTURE

Single file. No external CSS frameworks. No CDN dependencies. Vanilla JS only.

Two tabs:
  1. Explorer — user picks a focus angle from a dropdown; AI returns a structured response rendered as summary + table + follow-up chips
  2. Quiz — AI generates 5 multiple-choice questions; user answers one at a time; score tracked; explanation shown after each answer

Structure:
  <head>: meta charset, viewport, <style>
  <body>: <header>, tab bar, <main>, <footer>, <script>

---

  <p class="sub">[short topic description] · AI-powered explorer & quiz</p>

AI INFRASTRUCTURE

Copy this exactly — do not modify:

const PROXY = 'https://groq-proxy.ewalltom.workers.dev';
const MODEL = 'openai/gpt-oss-120b';

async function callAI(promptText) {
  const response = await fetch(PROXY, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      contents: [{ role: 'user', parts: [{ text: promptText }] }],
      generationConfig: { responseMimeType: 'text/plain' },
      model: MODEL
    })
  });
  const raw = await response.text();
  let data;
  try { data = JSON.parse(raw); }
  catch { throw new Error(`Non-JSON from proxy (HTTP ${response.status}): ${raw.slice(0,300)}`); }
  if (!response.ok) throw new Error(data?.error?.message || `HTTP ${response.status}`);
  const text = data?.candidates?.[0]?.content?.parts?.[0]?.text;
  if (!text) throw new Error('No text in AI response');
  return text;
}

function extractJson(text) {
  let t = String(text).trim();
  const fence = t.match(/```(?:json)?\s*([\s\S]*?)```/i);
  if (fence) t = fence[1].trim();
  const a = t.indexOf('{'), b = t.lastIndexOf('}');
  if (a >= 0 && b > a) t = t.slice(a, b + 1);
  try { return JSON.parse(t); } catch { return null; }
}

---

EXPLORER TAB

FOCUS_PROMPTS maps dropdown keys to dense knowledge strings. Write 5-8 entries based on the topic. Each string should:
  - Be a dense, specific paragraph — not a label, not a single sentence
  - Name real figures, dates, concepts, mechanisms where possible
  - Cover distinct angles of the topic

Example entry:
  "Origins": "The problem was first formalized by Dietrich Braess in 1968 while studying road networks in Stuttgart..."

Explorer AI prompt requests this JSON schema:
{
  "title": "",
  "summary": "",
  "items": [{ "name": "", "key_figure_or_date": "", "description": "", "significance": "" }],
  "follow_up_questions": [""]
}

Request 6-8 items. Follow-up questions render as clickable chips that re-run the explorer with that question as the focus.

---

QUIZ TAB

The quiz prompt embeds a knowledge scope string — a detailed paragraph naming the specific concepts, figures, dates, and mechanisms the questions should draw from. Be explicit and specific.

Request exactly 5 questions per batch. Schema:
{
  "questions": [{ "question": "", "options": ["A. ", "B. ", "C. ", "D. "], "correct": "A", "explanation": "" }]
}

Shuffle answer options before rendering (swap correct answer into a random position). Track previously asked questions across batches to avoid repeats. Show explanation after each answer.
